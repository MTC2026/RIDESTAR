Rumor 2.0 is a 3D browser voxel sandbox game featuring real-time online multiplayer without requiring server downloads!

Controls Guide

  • Desktop WASD to move | Space to jump
  • Mouse Click screen to look around
  • Left Click Break Block | Right Click Place Block
  • Keys 1-8 Switch Selected Block Type
  • Mobile Left Virtual Joystick to move, touch right screen to look around.
